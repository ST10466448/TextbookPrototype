TEXTBOOK CHECK — STUDENT WEBSITE PROTOTYPE

Files:
- index.html: page structure and accessible form fields
- style.css: layout, colours, responsive styling and focus indicators
- script.js: validation, recommendation logic, savings calculation, sharing and student tips

HOW TO RUN:
1. Extract the ZIP file to a folder on your computer.
2. Open Visual Studio Code.
3. Choose File > Open Folder and select the extracted should_i_buy_this_textbook folder.
4. Open index.html.
5. If you have the VS Code Live Server extension, right-click index.html and select "Open with Live Server".
   Otherwise, you can double-click index.html to open it in your browser.
6. Test the form using the examples in the assignment instructions below.

SUGGESTED TEST:
- Textbook title: Introduction to Programming
- New price: 900
- Required: Yes, it is required
- Usage: Every week
- Second-hand price: 450
- Alternatives: select Library copy
Expected behaviour: the page recommends considering the second-hand option and displays potential savings of R450.

PART 2 DESIGN EVIDENCE:
- Effectiveness: complete the form and confirm that a recommendation is shown.
- Efficiency: complete the short form and use one main action button.
- Safety: enter an invalid or missing price and check that an error appears.
- Utility: enter course requirements, usage frequency and alternatives.
- Learnability: ask someone unfamiliar with the page to complete the form without instructions.
- Memorability: ask the same person to return later and repeat the task.
- Interaction styles: form entry and button = instructing; changing options = manipulating; explanatory result = conversational feedback; "How it works" section = browsing/exploring.
- Social interaction: submit a textbook tip and use Share result.
- Emotional interaction: inspect the explanatory recommendation and savings message.
- WCAG 2.0: test keyboard-only navigation with Tab and Shift+Tab, visible focus, labels, contrast, and error messages.

IMPORTANT:
This is a prototype, not a live financial-advice service. Student tips are stored only in the current page session and are not uploaded. The recommendation logic is a simple demonstration and should not be presented as a guarantee.
